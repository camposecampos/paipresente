# Pai Presente

Landing page oficial do produto **Pai Presente — Desenvolvimento Infantil dos 12 aos 24 meses**, da Campos & Campos.

## Estrutura

- `index.html` — conteúdo da landing page
- `styles.css` — identidade visual e responsividade
- `script.js` — navegação e persistência básica de origem de campanha

## Publicação

O site é estático e compatível com GitHub Pages.

URL esperada após ativar o GitHub Pages:

https://camposecampos.github.io/paipresente/

## Checkout

Na versão inicial, os CTAs finais direcionam para o WhatsApp de suporte. Quando o checkout definitivo for definido, basta substituir os links com a classe `buy-now` no `index.html`.
